## 结论

- 固定夹具覆盖 L1 命中、L1 未命中、L2 完整通过和 L2 目录获取失败。L1 命中只发 1 次请求；
  L1 未命中是 `stage="no_results"`，不是 `unavailable`；空目录页在 L2 明确归到 `stage="toc_fetch"`。
- 全量导出中筛出 3171 条启用且有 `searchUrl` 的真实书源，用同一关键词「剑来」在并发 16 下分别跑
  L1 与 L2。L1 墙钟 3 分 57 秒，L2 墙钟 4 分 43 秒。
- L1 有 230 个成功行、按 `(sourceName, sourceUrl)` 去重后 169 个通过键；L2 有 25 个成功行、
  18 个通过键。18 个 L2 通过键全部包含在 L1 通过集合中，`L2-only=0`。
- 18 个共同成功键上，L1 总耗时 16846 ms、L2 总耗时 37305 ms，比值 2.21x；单源范围 1.08x 到 3.43x。

## Probe CLI

`probe detect` 直接调用 `runtime::detect`，两档都走真实 detect mode 路径，不使用 `search` 命令冒充 L1。

```sh
make probe ARGS='/tmp/t23-sources-all.json detect 剑来 --mode probe --concurrency 16 --json'
make probe ARGS='/tmp/t23-sources-all.json detect 剑来 --mode full --concurrency 16 --json'
```

`--mode` 只接受 `probe` / `full`，缺省 `full`；旧命令不变。显式 `--timeout` 仍可覆盖该档默认预算。

## 集合包含关系

按 `(sourceName, sourceUrl)` 去重，只把至少有一条成功结果的键计入通过集合：

- L1 通过集合大小：169。
- L2 通过集合大小：18。
- 交集：18。
- L2 有而 L1 没有：0。
- L1 有而 L2 没有：151。

结论：`L1 通过集合 ⊇ L2 通过集合`。本批没有集合反例。

复核命令：

```sh
jq -s '
  def key: [.sourceName,.sourceUrl] | join("\u0000");
  (.[0]|map(select(.ok))|unique_by(key)|map(key)) as $l1 |
  (.[1]|map(select(.ok))|unique_by(key)|map(key)) as $l2 |
  {l1Only:($l1-$l2|length), l2Only:($l2-$l1|length), common:($l1-($l1-$l2)|length)}
' /tmp/t23-l1-results.json /tmp/t23-l2-results.json
```

输出：`{"l1Only":151,"l2Only":0,"common":18}`。

## 反例与风险

### 重复定义造成逐行波动

`💯 连尚读书` / `http://www.lsds.cn/search` 在 3171 行中有两条同名同 URL 定义：

- L1 第一条：`ok=true` / `stage=search` / `184 ms`；第二条：`ok=false` / `stage=not_found` / `120 ms`。
- L2 两条均成功：`stage=content` / `2213` 字，分别 `632 ms`、`662 ms`。

这不是集合反例，因为该自然键在 L1 有成功结果；但它说明逐行成功率会被重复定义和瞬时网络波动污染。
集合判断必须先按自然键归并，同一键内采用「至少一次成功」，否则会出现同一逻辑源既算通过又算失败的歧义。

### 真实目录获取失败

`🔖九五小说①` / `http://m.95dushu.com` 在 L2 返回：

- `ok=false`
- `stage=toc_fetch`
- `contentLen=0`
- `elapsedMs=16590`
- `detail` 以目录 URL `http://m.95dushu.com/99/99407/` 开头，后接站点返回的 HTML

该失败没有归到 `unavailable`。详情响应看起来像书籍页而不是目录页，属于明确的目录获取阶段失败。

## 未验证与边界

- 没有在 HarmonyOS 真机执行 3171 或 3000 源单轮；以上耗时是 macOS 主机 release probe。
- 只跑了一轮，真实站点结果可能随网络、WAF、限流和书源更新变化。
- L1 命中率依赖关键词「剑来」与各源规则；不能外推成与关键词无关的通过率。
- 3171 条不是全量 3907 条，排除了禁用和没有 `searchUrl` 的条目。
- L2 跑的是同一批 3171 条，不是只跑 L1 通过子集；这适合核对集合包含关系，不代表生产应这样调度。
